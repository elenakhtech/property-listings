# CLAUDE.md

## What this is
A demo property listings page for a made-up brokerage called "Desert Key Realty (Demo)" in Las Vegas. It is a practice project. All listings are fictional sample data.

## Tech
- Plain HTML, CSS and JavaScript. No frameworks, no build step.
- Files: index.html, styles.css, app.js, listings.js
- Listing data lives in listings.js as a JavaScript array named LISTINGS, so the page works when index.html is opened directly in a browser.
- Must work on phones (responsive layout).

## Data rules
- All listings are made up: fictional street addresses, real Las Vegas area names (Summerlin, Henderson, Spring Valley, North Las Vegas, Downtown) are fine.
- No real company names, no real photos. Use simple colored placeholders instead of images.
- The page must clearly say "Demo – sample data only".

## Rules
- Explain every change in plain language, because the users are non-technical agents.
- Always work on a new branch, never commit directly to main.
- Show me the diff before saving any file.
- Keep README.md up to date when the page changes.
