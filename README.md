# property-listings
Demo property listings page with filters and search, built with Claude Code and deployed on Vercel. Sample data only.

## What's on the page (first version)
- A header with the name "Desert Key Realty (Demo)" and a yellow banner saying "Demo – sample data only".
- 8 made-up homes around Las Vegas. Each card shows a colored box where a photo would go, plus the price, address, neighborhood, bedrooms, bathrooms and square feet.
- The layout works on phones: 1 column on a phone, 2 on a tablet and 3 on a computer screen.
- Filters and search are not built yet.

## How to open it
Double-click `index.html` to open it in any web browser. You don't need to install anything.

## Files
- `index.html` – the page itself
- `styles.css` – colors, spacing and the phone-friendly layout
- `app.js` – turns the home data into cards on the page
- `listings.js` – the sample homes (edit this file to change them)
